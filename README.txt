OceUA 2.0.0
=============
Українські переклади для Turtle / Oce WoW (1.12):
квести · діалоги · книги · скіли · предмети · тултіпи

Команди:  /oceua   |   /oceskill reload | status | test


══════════════════════════════════════════════════════════════
  ЯК ДОДАВАТИ ПЕРЕКЛАДИ (коротко)
══════════════════════════════════════════════════════════════

Правило №1: ключ = ТОЧНИЙ англійський текст з гри (копіюй 1:1).
Правило №2: пиши лише в «свій» файл (див. таблицю нижче).
Правило №3: після змін у Data/ — /reload  або  /oceskill reload

НЕ пиши «в будь-який файл» — кожен файл відповідає за свій тип тексту.

══════════════════════════════════════════════════════════════
  ФОРМАТ ДЛЯ СКІЛІВ / ПРЕДМЕТІВ / РЕЦЕПТІВ (рядок → рядок)
══════════════════════════════════════════════════════════════

  ["English text exactly as in game"] = "Український переклад",

• Ключ у квадратних дужках у лапках.
• Значення — теж у лапках.
• Кома в кінці рядка обов’язкова (крім останнього перед }).
• Якщо в тексті є лапки " — екрануй: \"
• Якщо в тексті є $s1, $d, $52970s1 — ЗАЛИШАЙ їх і в перекладі
  (аддон підставить числа з гри).
• Порожнє значення "" = «ще не перекладено» (аддон пропустить).

Приклади:

  ["Hamstring"] = "Подрезання",
  ["Increases your chance to hit by $s1%."] = "Збільшує шанс влучити на $s1%.",
  ["Worn Shortsword"] = "Зношений короткий меч",


══════════════════════════════════════════════════════════════
  ФОРМАТ ДЛЯ КВЕСТІВ
══════════════════════════════════════════════════════════════

  [783] = {
      en = "A Threat Within",          -- точна англ. назва з гри (для пошуку)
      T  = "Загроза зсередини",        -- українська назва
      D  = "Опис квесту… $B$BДругий абзац. Привіт, $N.",
      O  = "Цілі…",
      P  = "Текст прогресу…",
      C  = "Текст здачі…",
  },

Коди (як у pfQuest):
  $B $b     — новий рядок
  $N $n     — ім’я гравця
  $C $c     — клас
  $R $r     — раса
  $g(прийшов;прийшла) — за статтю

ID квесту: wowhead / pfQuest / кнопка #ID у вікні квесту в грі.


══════════════════════════════════════════════════════════════
  ПОЗНАЧКИ $… (у грі = звичайні цифри)
══════════════════════════════════════════════════════════════

У словнику замість чисел стоять шаблони. Аддон підставляє
реальні значення з тултіпа. Не замінюй їх на «5» чи «30 сек».

  $s1  $s2  $s3     сума / шкода / % / броня ефекту №1,2,3
  $d   $D           тривалість (15 sec → 15 сек, 30 min → 30 хв)
  $t1  $t2          період тіку («кожні X сек»)
  $o1               сума за всю тривалість (DoT / HoT)
  $a1               радіус
  $m1  $M1          мін / макс (діапазон шкоди)
  $h                шанс спрацювання (proc %)
  $n                заряди
  $u                макс. стаків
  $x   $i           макс. цілей
  $z                назва зони (Hearthstone)
  $20168s1          значення зі скіла ID 20168
  $7922d            тривалість зі скіла ID 7922
  $g(he;she)        стать (чол;жін)
  $l(point:points;) однина / множина

Квести / книги:
  $B $b   новий рядок
  $N $n   ім’я гравця
  $C $c   клас
  $R $r   раса
  $g(прийшов;прийшла)  стать

Повний список з прикладами: Data/ПОЗНАЧКИ.txt


══════════════════════════════════════════════════════════════
  ЯК ПРАЦЮЄ ПОШУК (скіли / тултіпи)
══════════════════════════════════════════════════════════════

1) soft-exact  — регістр і пробіли нормалізуються, ЧИСЛА лишаються
                 ("Increased Hit Chance 5" ≠ "... 3")
2) template    — числа і $s1/$d → "#", колізії: пріоритет шаблонам з $
3) підрядок    — якщо шаблон покриває ≥65% тексту

Після змін у словниках:
  /oceskill reload   — перечитати без релогу гри
  /reload             — повний перезапуск аддонів
