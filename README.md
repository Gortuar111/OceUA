# OceUA
OceUA - представляє собою аддон, який перекладає текст в грі Українською мовою поверх Англійської - для OctoWow

що перекладено:
- Books - книги
- Quests - квести (при взятті та при здачі кв)
- Gossip - діалоги NPC
- Items - предмети
- NPC Names - Імена NPC
- Mobs - назви мобів
- Objects - об'єкти
- Recipes - рецепти
- Reputation - репутація
- Signs/Zones - вивіски/вказівники
- Skills - скіли та описи до них
- та різні інші дрібниці

мова тут лише одна - Українська

є окремі налаштування та корисні фічі

Гарної гри!)
